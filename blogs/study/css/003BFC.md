## BFC（Block Formatting Context）

BFC（**Block Formatting Context，块级格式化上下文**）是 CSS 中的一种**独立布局环境**。

可以把它理解成一个**隔离的容器**：

- 内部元素不会影响外部元素
- 外部元素也不会影响内部元素
- 内部按照自己的布局规则进行排版

一句话概括：

> **BFC 就是一个独立的块级布局环境。**


创建 BFC 后，会遵循以下规则：

#### 1、内部元素垂直排列

块级元素会按照普通文档流，从上到下排列。

```html
<div class="box1"></div>
<div class="box2"></div>
```

#### 2、内部布局不会影响外部

BFC 内部元素的布局变化不会影响外部元素。

例如：

- 内部浮动不会影响外部布局
- 外部浮动也不会影响 BFC 内部布局


#### 3、计算高度时会包含浮动元素

普通情况下：

```css
.child {
  float: left;
}
```

由于浮动元素脱离普通文档流，父元素可能发生**高度塌陷**。

如果父元素形成 BFC：

```css
.parent {
  overflow: hidden;
}
```

那么 BFC 在计算高度时会包含浮动元素，因此父元素高度恢复正常。


#### 4、不会与浮动元素重叠

如果左侧元素浮动：

```css
.left {
  float: left;
  width: 200px;
}
```

右侧元素形成 BFC：

```css
.right {
  overflow: hidden;
}
```

右侧内容会自动避开左侧浮动，实现经典的：

> 左固定 + 右自适应布局


#### 5、同一个 BFC 内垂直 上下Margin 会折叠

例如：

```css
.box1 {
  margin-bottom: 20px;
}

.box2 {
  margin-top: 30px;
}
```

实际间距：30px而不是：50px


因为垂直 Margin 会发生折叠（Margin Collapse）。

如果两个元素属于**不同 BFC**，则不会发生 Margin 折叠。


### 如何创建 BFC？

常见创建方式如下：

| 方式 | 是否创建 BFC |
| ---- | ------------ |
| `overflow` 不为 `visible` | ✅ |
| `float` 不为 `none` | ✅ |
| `position: absolute` | ✅ |
| `position: fixed` | ✅ |
| `display: inline-block` | ✅ |
| `display: table-cell` | ✅ |
| `display: table-caption` | ✅ |
| `display: flow-root` | ✅ |
| Flex Item | ✅ |
| Grid Item | ✅ |

> **现代开发推荐使用 `display: flow-root` 创建 BFC，语义更明确，也不会产生 `overflow: hidden` 带来的裁剪问题。**



### BFC 有哪些作用？（重点）

#### 1、清除浮动（解决高度塌陷）

#### 问题

```html
<div class="parent">
  <div class="child"></div>
</div>
```

```css
.child {
  float: left;
}
```

由于浮动脱离普通文档流，父元素高度可能变为 0。

---

#### 解决方案

```css
.parent {
  overflow: hidden;
}
```

或者：

```css
.parent {
  display: flow-root;
}
```

形成 BFC 后，父元素会计算浮动元素的高度，从而解决高度塌陷。


#### 2、解决 Margin 折叠

例如：

```css
.box1 {
  margin-bottom: 20px;
}

.box2 {
  margin-top: 30px;
}
```

最终间距只有：

```
30px
```

如果把其中一个元素放进新的 BFC：

```html
<div class="wrapper">
  <div class="box1"></div>
</div>

<div class="box2"></div>
```

```css
.wrapper {
  overflow: hidden;
}
```

由于它们不再属于同一个 BFC，因此：

```
20 + 30 = 50px
```

Margin 不再折叠。


#### 3、解决父子 Margin 合并（Margin 穿透）

例如：

```html
<div class="parent">
  <div class="child"></div>
</div>
```

```css
.child {
  margin-top: 50px;
}
```

最终表现为：

整个父元素一起向下移动。

这是父子 Margin 合并导致的。

解决方式：

```css
.parent {
  overflow: hidden;
}
```

或者：

```css
.parent {
  display: flow-root;
}
```


#### 4、实现左固定右自适应布局

```html
<img class="left" />

<div class="right">
  很多很多文字……
</div>
```

```css
.left {
  float: left;
  width: 200px;
}

.right {
  overflow: hidden;
}
```

效果：

```
+------+----------------------+
| 图片 |       文字内容       |
|      | 自动占满剩余宽度     |
+------+----------------------+
```

这是 BFC 最经典的应用之一。

---

### 为什么 `overflow: hidden` 能清除浮动？

很多人会背：

> `overflow: hidden` 可以清除浮动。

实际上真正起作用的是 **BFC**。

整个过程如下：

```
overflow: hidden
        ↓
创建 BFC
        ↓
BFC 在计算高度时会包含浮动元素
        ↓
父元素恢复高度
```

因此：

> **真正解决高度塌陷的是 BFC，而不是 `overflow` 本身。**


### 为什么推荐使用 `display: flow-root`？

现代 CSS 提供了专门用于创建 BFC 的属性：

```css
.parent {
  display: flow-root;
}
```

优点：

- 语义明确（就是为了创建 BFC）
- 不会裁剪内容
- 不会产生滚动条
- 不会影响 `position: sticky`
- 比 `overflow: hidden` 更适合现代项目

因此：

> **新项目优先推荐 `display: flow-root`。**


## FC（Formatting Context）是什么？

FC（Formatting Context）即**格式化上下文**，表示页面中的一种布局环境。

不同布局模式对应不同类型的 FC。

常见的有：

| 类型 | 全称 | 用途 |
| ---- | ---- | ---- |
| BFC | Block Formatting Context | 块级布局 |
| IFC | Inline Formatting Context | 行内布局 |
| FFC | Flex Formatting Context | Flex 布局 |
| GFC | Grid Formatting Context | Grid 布局 |


### IFC（Inline Formatting Context）


IFC（**Inline Formatting Context，行内格式化上下文**）是用于排列**行内元素**的布局环境。

例如：

```html
<span>HTML</span>
<span>CSS</span>
<span>JavaScript</span>
```

它们会从左到右排列，并形成一行（Line Box）。

---

### IFC 的特点

#### 1、行内元素水平排列

```html
<span>A</span>
<span>B</span>
<span>C</span>
```

效果：

```
A B C
```

---

#### 2、宽度不足时自动换行

形成多个 **Line Box**：

```
A B C D
E F G
```

---

#### 3、Line Box 高度由最高元素决定

例如：

```html
<span>文字</span>
<img height="80" />
```

这一行的高度就是：

```
80px
```

---

#### 4、Float 会影响 IFC

浮动元素会占据空间，导致文字绕排。

例如：

```css
img {
  float: left;
}
```

后面的文字会围绕图片排列。

---

#### 5、块级元素不能直接出现在 IFC 中

例如：

```html
<p>
  文本
  <div></div>
</p>
```

浏览器会自动结束当前 IFC，生成匿名块盒（Anonymous Block Box），再重新开始新的 IFC。

---

### IFC 的应用

##### 水平居中（传统方案）

```css
.parent {
  text-align: center;
}

.child {
  display: inline-block;
}
```

利用 IFC 中 `text-align` 的特性实现水平居中。

---

#### 垂直居中（传统方案）

```css
.parent {
  line-height: 100px;
}

.child {
  vertical-align: middle;
}
```

或者：

```css
display: inline-block;
vertical-align: middle;
```

> **现代开发更推荐使用 Flex 或 Grid 实现居中。**

---

### 面试回答

**什么是 BFC？**

> BFC（Block Formatting Context）是 CSS 中的块级格式化上下文，可以理解为一个独立的布局环境，内部元素不会影响外部，外部元素也不会影响内部。

**如何创建 BFC？**

- `overflow` 不为 `visible`
- `float` 不为 `none`
- `position: absolute / fixed`
- `display: inline-block`
- `display: flow-root`
- Flex Item、Grid Item

**BFC 有哪些作用？**

1. 清除浮动，解决父元素高度塌陷
2. 防止 Margin 折叠和父子 Margin 合并
3. 实现左固定右自适应布局

**为什么 `overflow: hidden` 能清除浮动？**

> 因为它创建了 BFC，而 BFC 在计算高度时会包含浮动元素，因此父元素能够恢复高度。

**为什么推荐 `display: flow-root`？**

> 它专门用于创建 BFC，不会像 `overflow: hidden` 一样裁剪内容或影响滚动，语义更清晰，也是现代 CSS 更推荐的方案。
